Pipeline Stages

×
1. Ingest
Read from FlashBlade - Load transaction records from parquet file. Demonstrates read throughput from high-performance storage.
2. Data Prep
Feature Engineering + Write to FlashBlade - Transform raw data into 21 ML features including amount statistics, time-based features, geographic distance, and categorical encoding. Write prepared features to storage.
3. Model Train
Read + XGBoost Training - Read transaction features from FlashBlade, then train XGBoost gradient boosting classifier with 100 rounds. Both paths use XGBoost - CPU path vs GPU-accelerated path.
4. Inference
Score + Write to FlashBlade - Run fraud predictions on all records and write scored results with fraud probability scores back to storage.
Demo Purpose: Compare CPU vs GPU performance across a complete ML fraud detection pipeline, showcasing how high-throughput storage like FlashBlade can keep pace with GPU-accelerated workloads.

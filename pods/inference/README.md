# Triton Inference Server Configuration

This directory contains configuration files for NVIDIA Triton Inference Server.

## Configuration Files

The actual model configurations (`config.pbtxt`) are generated automatically by **Pod 3 (Model Build Service)** and placed in the model repository on FlashArray storage.

## Model Repository Structure

```
FA_MOUNT/model_repository/
├── fraud_xgboost/
│   ├── config.pbtxt          # Generated by Pod 3
│   └── 1/
│       └── model.json        # XGBoost model file
└── fraud_gnn/
    ├── config.pbtxt          # Generated by Pod 3 (if implemented)
    └── 1/
        └── model.pt          # PyTorch GNN model
```

## Custom Configuration

If you need to customize Triton server settings, you can add:
- `triton_config.json` - Server-level configuration
- Custom backends or preprocessing scripts

These configurations will be loaded at runtime from this directory.
